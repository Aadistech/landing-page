# TransX – Smart Urban Mobility Landing Page

## 🚀 Project Overview  
TransX is an all-in-one urban- & rural-mobility landing page for the project by Aadistech. This website introduces the project, highlights the team, and presents the vision for seamless, smart, safe, and eco-friendly transportation.

## 🎯 Key Features  
- Clean, modern design with a dark gradient background for a high-tech look  
- Hero section featuring the HexMindTech branding & tagline  
- “About” section: explains the mission and goals of TransX  
- “Meet the Team” section: profiles team members with images and roles  
- Mobile-friendly and responsive layout  

## 🛠 Built With  
- HTML5 & CSS3  
- Google Font: Poppins (for the HexMindTech heading)  
- Vanilla JavaScript for modal pop-ups (if used)  
- SVG / JPG / PNG images for logos and team photos  

## 🎨 Branding & Style  
- Brand gradient for the “HexMindTech” heading: `linear-gradient(90deg, #1D2661, #18A287, #6B2D90)`  
- Dark background palette: `#0f1724` → `#071028`  
- Accent color: `#06b6d4`  
- Font family for heading: Poppins; body: Inter / Arial / sans-serif
