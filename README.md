## 🧠 About TransX  
**TransX** is a futuristic **urban mobility platform** designed by **Team HexMindTech** under Aadistech.  
It focuses on simplifying urban transportation using intelligent systems, data-driven planning, and an eco-friendly approach.  

Our mission is simple:  
> “Empower smart cities with technology-driven, seamless, and sustainable mobility solutions.”
